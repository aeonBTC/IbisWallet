# Ibis Wallet

Ibis — модульный Bitcoin-кошелёк с самохранением, ориентированный на интуитивный дизайн, приватность и настраиваемость.

Для опытных пользователей — без обучения и «страховки».

## Ключевые возможности

### Layer 1 — Bitcoin
- **Мультикошелёк** - Создание, импорт, экспорт и переключение между несколькими кошельками
- **Мультисид** - Импорт seed-фраз BIP39 или Electrum
- **Энтропия кубика** - Генерация сидов из бросков кубиков
- **Multisig-кошельки** - Импорт multisig-дескрипторов, координация подписи PSBT и локальная подпись как со-подписант
- **Watch-only-кошельки** - Импорт xpub/zpub, output-дескрипторов или одного адреса
- **Импорт приватного ключа** - Свип или импорт приватных ключей (формат WIF)
- **Тихие платежи** - Полная поддержка BIP-352: отправка и получение, с сервером Frigate по умолчанию
- **Подпись аппаратным кошельком** - Анимированные QR-коды или файлы .psbt для air-gapped подписи
- **Подпись PSBT по NFC** - Отправка PSBT на аппаратный кошелёк касанием NFC и получение подписи тем же способом
- **Офлайн-подписант** - Ibis на устройстве без интернета как холодный подписант PSBT наблюдаемого кошелька.
- **Защита от dust** - Помечает подозрительный dust и исключает его из автовыбора монет
- **Контроль монет** - Выбор конкретных UTXO, заморозка/разморозка, отправка с отдельных выходов
- **Обязательный контроль монет** - Опция принудительного выбора UTXO перед on-chain отправкой
- **RBF и CPFP** - Повышение комиссии неподтверждённых транзакций, включая безопасные для multisig PSBT-потоки
- **RBF по умолчанию** - On-chain отправки по умолчанию сигналят replace-by-fee; можно отключить
- **Отмена транзакций** - Отмена неподтверждённых исходящих транзакций через RBF
- **Ручная трансляция** - Прямая трансляция любой подписанной raw-транзакции в сеть Bitcoin
- **Пакетная отправка** - Отправка нескольким получателям в одной транзакции
- **Подпись сообщений** - Подпись и проверка сообщений по BIP137
- **Помощник контрольной суммы** - Вычисление недостающего контрольного слова из префикса в 11/23 слов
- **Метки BIP329** - Стандартные метки кошелька для транзакций и адресов
- **Поиск транзакций** - Поиск истории по дате, адресу или метке
- **На основе** [BDK](https://bitcoindevkit.org/)

### Layer 2 — нативный Lightning, Ark, Spark и Liquid
- **Модульная интеграция** - Выбор Layer 2 для каждого кошелька
- **Lightning** - Подключение удалённой ноды через LND (LND REST), CLN (clnrest) или NWC (NIP-47)
- **Ark** - Ark L2 с управлением VTXO, отправкой и получением Lightning, boarding одной транзакцией и односторонними выходами (На основе [Bark](https://github.com/ark-bitcoin/bark))
- **Spark** - Spark L2 с отправкой и получением Lightning и on-chain, и односторонними выходами (На основе [Breez-SDK](https://github.com/breez/spark-sdk))
- **Liquid** - Полноценный Liquid-кошелёк с конфиденциальными транзакциями и поддержкой USDt (На основе [LWK](https://github.com/Blockstream/lwk))
- **Watch-only-кошельки Liquid** - Импорт watch-only Liquid-кошельков через дескрипторы SLIP77
- **Lightning-платежи** - Оплата инвойсов Bolt 11 и Bolt 12, а также Lightning-адресов
- **Lightning-инвойсы** - Создание инвойсов Bolt 11
- **Chain-свопы** - Простой обмен между L1 и L2
- **Контроль монет** - Выбор конкретных UTXO для свапов и платежей
- **Метки BIP329** - Метки для транзакций Ark, Spark и Liquid

### Приватность и безопасность
- **Офлайн по умолчанию** - Запуск без внешних подключений
- **Встроенный Tor** - Встроенный Tor, без Orbot и внешних прокси
- **PIN и биометрия** - С настраиваемым временем блокировки
- **PIN принуждения** - PIN принуждения, открывающий кошелёк-приманку
- **PIN стирания** - Настройка второго PIN, который молча стирает все данные кошелька на устройстве
- **Автостирание** - Порог неудачных разблокировок с автоматическим и необратимым стиранием всех данных приложения
- **Очистка буфера обмена** - Опция автоматически очищать буфер обмена при блокировке или закрытии приложения
- **Режим маскировки** - Маскировка Ibis под приложение-калькулятор
- **Переключатель приватности** - Скрытие всех сумм и балансов
- **Стирание истории** - Локальное стирание отдельных транзакций или всей истории
- **Блокировка кошельков** - Независимая блокировка отдельных кошельков
- **Усиленные метаданные** - Очищенные логи и UI-ошибки для снижения метаданных, видимых ОС

### Подключение и серверы
- **Свои серверы** - Свои серверы Electrum, block explorer и оценки комиссии
- **Поддержка NFC** - Передача и приём платёжных запросов по NFC
- **Уведомления об обновлениях** - Уведомления о новых версиях
- **Обработка Bitcoin URI** - Обработка ссылок `bitcoin:`

### Локализация
- **Языки** - Английский, испанский, русский, португальский (Бразилия), французский, немецкий, японский и упрощённый китайский
- **Шрифт** - Несколько вариантов шрифта

### Резервное копирование и восстановление
- **Полные зашифрованные резервные копии** - Резервное копирование и восстановление всего состояния приложения, включая кошельки, настройки и метки

## Сборка

Требуется Android Studio с JDK 17.

```bash
./gradlew :app:assembleDebug      # Debug
./gradlew :app:assembleRelease    # Release
./gradlew testDebugUnitTest       # Тесты
./gradlew jacocoUnitTestReport    # Отчёт о покрытии
```

**Min SDK:** 26 (Android 8.0) | **Target SDK:** 36 | **ARM** (armeabi-v7a, arm64-v8a)

## Bug Bounty

> [!IMPORTANT]
> **Программа bug bounty приостановлена из-за отсутствия финансирования.** Отчеты приветствуются и будут отмечены, но денежные вознаграждения не будут выплачиваться до возобновления программы.

Мы выплачиваем $1,000 в BTC за критические уязвимости в Ibis Wallet, которые могут привести к несанкционированной потере средств пользователя.

В scope — уязвимости с практическим реалистичным путём атаки, ведущим к краже или безвозвратной потере средств (например, удалённый компромисс кошелька, извлечение seed, манипуляция транзакциями и т.п.).

Ibis — бета-версия для опытных пользователей биткоина. Резервная копия seed вне устройства — ожидаемая стандартная практика: проблемы, полностью устранимые восстановлением из seed без кражи третьими лицами, принимаются к сведению, но не вознаграждаются.

Менее серьёзные проблемы, теоретические уязвимости без практического exploit-пути или находки без потери средств будут приняты к сведению, но обычно не оплачиваются.

Выплаты по bug bounty: [15 августа 2026](https://github.com/aeonBTC/IbisWallet/releases/tag/v4.7.0-beta)
