# Ibis Wallet

Ibisは、直感的なデザイン、プライバシー、カスタマイズ性を重視した、セルフカストディ型のモジュラーBitcoinウォレットです。

経験豊富なユーザー向けに設計されています — 手取り足取りの説明も、補助輪もありません。

## 主な機能

### Layer 1 — Bitcoin
- **マルチウォレット** - 複数のウォレットの作成、インポート、エクスポート、切り替え
- **マルチシード** - ウォレットのインポートにBIP39またはElectrumシードフレーズをサポート
- **サイコロエントロピー** - サイコロの出目からシードを生成
- **マルチシグウォレット** - マルチシグディスクリプタのインポート、PSBT署名の調整、共同署名者としてのローカル署名
- **ウォッチオンリーウォレット** - xpub/zpub、出力ディスクリプタ、または単一アドレスのインポート
- **秘密鍵のインポート** - 秘密鍵のスイープまたはインポート（WIF形式）
- **サイレントペイメント** - BIP-352完全対応：送受信、デフォルトサーバーはFrigate
- **ハードウェアウォレット署名** - エアギャップ鍵署名にアニメーションQRコードまたは.psbtファイルを使用
- **NFC PSBT署名** - NFCタップでハードウェアウォレットにPSBTを送信し、同じ方法で署名を受け取る
- **オフライン署名** - オフライン端末のIbisをウォッチオンリーPSBT用コールドストレージ署名機として使用。
- **ダスト保護** - 疑わしいダストを検出し、自動コイン選択から除外
- **コインコントロール** - 特定のUTXOを選択、フリーズ/アンフリーズ、個別のアウトプットから送金
- **コインコントロール必須** - オンチェーン送金前にUTXO選択を必須にするオプション
- **RBFとCPFP** - 未確認トランザクションの手数料引き上げ（マルチシグ対応のPSBT手数料引き上げフロー含む）
- **RBFをデフォルトで** - オンチェーン送金はデフォルトでreplace-by-feeを通知；無効化可能
- **トランザクションのキャンセル** - RBFで未確認の送金トランザクションをキャンセル
- **手動ブロードキャスト** - 署名済みrawトランザクションをBitcoinネットワークに直接ブロードキャスト
- **一括送金** - 複数の宛先への送金を単一トランザクションで実行
- **メッセージ署名** - BIP137によるメッセージの署名と検証
- **チェックサムヘルパー** - 11/23単語のプレフィックスから不足チェックサム単語を算出
- **BIP329ラベル** - トランザクション・アドレス用の業界標準ウォレットラベル
- **トランザクション検索** - 日付、アドレス、ラベルでトランザクション履歴を検索
- **基盤** [BDK](https://bitcoindevkit.org/)

### Layer 2 — ネイティブLightning、Ark、Spark、Liquid
- **モジュール式統合** - ウォレットごとに有効化するLayer 2を選択
- **Lightning** - LND（LND REST）、CLN（clnrest）、NWC（NIP-47）経由でリモートノードに接続
- **Ark** - VTXO管理、Lightning送受信、単一トランザクションのボーディング、一方的エグジットを備えたArk L2（[Bark](https://github.com/ark-bitcoin/bark)ベース）
- **Spark** - Lightning・オンチェーン送受信と一方的エグジットを備えたSpark L2（[Breez-SDK](https://github.com/breez/spark-sdk)ベース）
- **Liquid** - コンフィデンシャルトランザクションとUSDt対応のフルLiquidウォレット（[LWK](https://github.com/Blockstream/lwk)ベース）
- **Liquidウォッチオンリーウォレット** - SLIP77ディスクリプタを使ったLiquidウォッチオンリーウォレットのインポート
- **Lightning支払い** - Bolt 11・Bolt 12インボイス、Lightningアドレスへの支払い
- **Lightningインボイス** - Bolt 11インボイスの生成
- **チェーンスワップ** - L1とL2間のスワップを簡単に実行
- **コインコントロール** - スワップ・支払い用のUTXO選択
- **BIP329ラベル** - Ark・Spark・Liquidトランザクションのラベル対応

### プライバシーとセキュリティ
- **デフォルトでオフライン** - アプリ起動時は外部接続ゼロ
- **Tor内蔵** - Torをネイティブ統合、Orbotや外部プロキシ不要
- **PINと生体認証** - ロックタイミングを設定可能なPIN・生体認証
- **ダレスPIN** - おとりウォレットを開くダレスPINを設定
- **ワイプPIN** - デバイス上の全ウォレットデータを密かに消去するセカンダリPINを設定
- **自動ワイプ** - ロック解除失敗回数のしきい値を設定し、到達時に全アプリデータを自動的かつ不可逆的に消去
- **クリップボード消去** - アプリのロック時・終了時にクリップボードを自動消去するオプション
- **偽装モード** - Ibisを電卓アプリに偽装
- **プライバシー切替** - 全てのウォレット金額・残高を非表示
- **履歴消去** - 特定ウォレットのトランザクションまたは履歴全体をローカルで消去
- **ウォレットロック** - 特定ウォレットを個別にロック
- **強化メタデータ** - OS可視メタデータ削減のためのログ・UIエラー無害化

### 接続とサーバー
- **カスタムサーバー** - 独自のElectrum、ブロックエクスプローラー、手数料推定サーバーに接続
- **NFC対応** - NFCタップによる支払いリクエストの配信・受信
- **アップデート通知** - 新バージョン通知の切り替え
- **Bitcoin URI処理** - `bitcoin:`リンクのハンドラーとして登録

### ローカリゼーション
- **言語** - 英語、スペイン語、ロシア語、ポルトガル語（ブラジル）、フランス語、ドイツ語、日本語、簡体字中国語
- **書体** - 複数の書体設定

### バックアップと復元
- **完全暗号化バックアップ** - ウォレット、設定、ラベルを含むアプリ全体の状態をバックアップ・復元

## ビルド

Android StudioとJDK 17が必要です。

```bash
./gradlew :app:assembleDebug      # Debug
./gradlew :app:assembleRelease    # Release
./gradlew testDebugUnitTest       # テスト
./gradlew jacocoUnitTestReport    # カバレッジレポート生成
```

**最小SDK:** 26 (Android 8.0) | **ターゲットSDK:** 36 | **ARM** (armeabi-v7a, arm64-v8a)

## バグバウンティ

> [!IMPORTANT]
> **バグバウンティプログラムは資金不足のため現在停止中です。** 報告は歓迎し謝意を示しますが、プログラム再開まで金銭的報酬は支払われません。

Ibis Walletのユーザー資金の不正な損失につながる重大な脆弱性に対し、BTCで1,000ドルを支払います。

バウンティ対象は、ユーザーの資金の盗難または永久的な損失につながる実用的で現実的な攻撃経路を与える脆弱性です（例：ウォレットのリモート侵害、シード抽出、トランザクション改ざんなど）。

Ibisはベータ版ソフトウェアであり、経験豊富なBitcoinユーザー向けに作られています。オフデバイスのシードバックアップは標準的な運用として想定されています：シードからの復元で完全に回復可能で、第三者による盗難を伴わない問題は認知されますが、報酬対象外です。

重大度が低い問題、実用的な悪用経路のない理論的な脆弱性、資金損失につながらない発見は認知されますが、原則として金銭的報酬の対象外です。

バグバウンティの受賞：[2026年8月15日](https://github.com/aeonBTC/IbisWallet/releases/tag/v4.7.0-beta)
